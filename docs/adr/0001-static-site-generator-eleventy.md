# 0001 — Збирати сайт генератором Eleventy зі статичним HTML на виході

- **Status:** Accepted
- **Date:** 2026-09-05
- **Deciders:** Yuriy Sobakar + SDD survey (foundation session)

## Context

Новий сайт-візитка — одна сторінка на статичному хостингу Netlify, зміст якої береться з одного файлу даних і має друкуватися як резюме. Старий сайт був чистим HTML, який доводилося правити руками, через що він застиг на рік. Потрібен спосіб підставляти дані в HTML без клієнтського JavaScript і без важкого фреймворку.

## Decision drivers

- Сумісність із Netlify: команда збірки + папка публікації (бриф §4, побажання власника).
- «Чистий HTML» на виході: SEO, швидкість, коректний друк (бриф §7, позиціювання власника як SEO-фахівця).
- Один файл даних як джерело правди, правка за 5 хвилин (бриф §7, ризик «сайт знову застигне» §6).
- Розмір XS і профіль Pro: мінімум інструментів і залежностей.
- Власник знає HTML/CSS/JS; вивчати новий фреймворк — небажана вартість.

## Considered options

1. **Astro + TypeScript** — статичний генератор із компонентами і перевіркою схеми даних; повноцінний фреймворк.
2. **Vite + React + TypeScript** — SPA, рендер у браузері через JavaScript.
3. **Чистий HTML + власний скрипт збірки на Node** — самописний шаблонізатор, dev-сервер і перевірка даних.
4. **Eleventy (11ty): HTML-шаблони Nunjucks + файл даних** — мінімальний генератор без фреймворку і без JS у браузері.
5. **Без збірки: JavaScript у браузері читає JSON** — статичний index.html, дані підвантажуються на клієнті.

## Decision outcome

**Chosen:** Option 4, Eleventy. Дає «чистий HTML» на виході й відчуття звичайної верстки (HTML + `{{ }}`), при цьому шаблонізатор, цикли, dev-сервер і підключення YAML — готові, а не самописні. Netlify збирає його стандартно (`npx @11ty/eleventy`, публікація `_site`). Astro відкинуто як важчий інструмент для однієї сторінки; React і клієнтський JSON — через рендер у браузері (SEO, порожня сторінка без JS); власний скрипт — через вартість підтримки.

## Consequences

**Positive**
- Нуль JavaScript у браузері; сторінка індексується і друкується як звичайний HTML.
- Зміна змісту = правка YAML, без дотику до шаблонів.
- Одна легка залежність (`@11ty/eleventy`), швидка збірка, стандартний деплой на Netlify.

**Negative**
- Nunjucks — новий синтаксис шаблонів для власника (невеликий, але є).
- Інтерактивність понад `window.print()` потребуватиме окремого рішення (ADR), бо фундамент її не передбачає.

**Neutral**
- Перехід на Astro пізніше можливий: дані у YAML і CSS переносяться без змін, переписуються лише шаблони.
