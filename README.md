# yuriy-sobakar-site

One-page resume of Yuriy Sobakar — a static site generated by [Eleventy](https://www.11ty.dev/) from a
single YAML file, with a **publish gate** that stops the build on unsafe data, a print view that doubles as
the PDF, and no client-side JavaScript beyond three small, documented exceptions.

**Live:** https://yuriy-sobakar.netlify.app/

## How it works

```
src/_data/resume.yaml  →  JSON Schema  →  rules.js  →  view-model.js  →  Nunjucks templates  →  _site/
                          (shape)         (invariants)  (safe presentation)
```

- **One source of truth.** Every word on the page comes from `src/_data/resume.yaml`; templates only
  loop and print. Section order and headings live in the YAML too.
- **Publish gate** (`lib/resume/`). The schema checks shape (required fields, 1–3 hero facts, date formats);
  `rules.js` checks cross-field invariants a schema cannot express — e.g. a commercial project may never
  link to its code, a confidential project never exposes the client's name. A violation stops the build
  with a field-level message, so a broken edit can never publish an empty or leaking page:

  ```
  resume data is invalid — the build was stopped:
    src/_data/resume.yaml › projects.0 "Acme Storefront": the code of a commercial project is not published — remove links.code
  ```

- **View model.** Sorting (newest first), the `Present` flag, empty-section removal and the
  confidential strip happen in `lib/resume/view-model.js`, never in templates.
- **Design.** Vanilla CSS with design tokens (`src/styles/tokens.css`), mobile-first, self-hosted
  Montserrat subset (18 KB) with a metric-matched fallback so nothing shifts while it loads. The print
  stylesheet turns the same page into a 3-page A4 resume (the **Print** button opens the browser dialog,
  which also saves a PDF).
- **JavaScript.** Exactly three pieces, each with an ADR: `window.print()`, an optional cookie-less
  contact-click counter, and the **Share** button (Web Share API with a clipboard fallback). The build
  test fixes the `<script>` count.

## Commands

```bash
npm install
npm test          # node --test: schema, rules, view model, and full builds on fixtures (51 tests)
npm run build     # eleventy --input=src → _site/
npm run lint      # html-validate over the built HTML
npm run dev       # local server with live reload
```

Hosting: Netlify builds `main` on every push (`netlify.toml`); CI runs test + build + lint on GitHub Actions.

## Editing the resume

Edit `src/_data/resume.yaml` and push. A new field goes into `src/_data/resume.schema.json` first;
a new cross-field rule is one function in `lib/resume/rules.js` plus one test. Conventions for
contributors (human or AI) are in [`CLAUDE.md`](CLAUDE.md).

## Project structure

```
src/
  _data/            resume.yaml (content), resume.schema.json (contract), site.json (settings)
  _includes/        layout.njk, contact-button.njk, sections/*.njk, icons/*.njk
  styles/           tokens.css, base.css, layout.css, print.css
  assets/           photo, self-hosted font
lib/resume/         load.js, rules.js, code-hosts.js, view-model.js  — the publish gate
test/               node --test suites + YAML fixtures
docs/               brief, architecture map, roadmap, ADRs, feature artifacts
```

The code is free to reuse as a template; the resume content and the photo belong to Yuriy Sobakar.
